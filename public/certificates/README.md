# Your Certificate PDFs

Drop your real certificate PDFs in this folder. The site links each
certification to its file so visitors can view it.

Expected filenames (used by the seed data):

    CCNA-Introduction-to-Networks.pdf
    Ethical-Hacker.pdf
    Endpoint-Security.pdf
    Network-Support-and-Security.pdf
    Network-Technician-Career-Path.pdf
    Networking-Devices-and-Initial-Configuration.pdf
    Networking-Basics.pdf
    Introduction-to-Cybersecurity.pdf
    Computer-Hardware-Basics.pdf
    Operating-Systems-Basics.pdf
    ITIL-4-Foundation.pdf

If a file is missing, that certificate simply shows without a
"View Certificate" button — nothing breaks.

**Easiest method:** log into `/admin` → **Certificates & Skills** →
"Certificate PDF (optional)" → Upload. That stores the file in the
database and links it immediately, with no renaming needed.
